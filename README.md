# SkillSwap + TimeMarket + FixMatch

Plataforma Web e Mobile de troca de habilidades e tempo, com matching inteligente, TimeCredits e identificação de necessidades via FixMatch.

## Estrutura

- `backend/` — API em Python com FastAPI
- `frontend/` — aplicação Web em HTML, CSS e JavaScript
- `mobile/` — aplicativo em .NET MAUI
- `docs/` — documentação do projeto
